# Cloud.ru Bug Bounty

Cloud.ru — провайдер облачных сервисов и ИИ-технологий. 130+ IaaS/PaaS-сервисов, платформа Cloud.ru Evolution, AI Factory для GenAI.

## Область действия

Личный кабинет и сервисы облачной платформы Cloud.ru Evolution.

### Домены для тестирования

- Консоль: `console.cloud.ru/*`
- API сервисов: `*.api.cloud.ru`
- Документация: `https://cloud.ru/docs`

### Доступные сервисы

Только сервисы на стадии General Availability (без запроса через поддержку).

## Идентификация трафика

HTTP-заголовок `X-Bug-Bounty: {Username}` на всех запросах.

## Политика RCE

Разрешено:
- `ifconfig` / `ipconfig`, `hostname`, `whoami`
- Чтение `/etc/passwd` и `/proc/sys/kernel/hostname`
- Создание пустого файла в каталоге текущего пользователя

Иные действия — согласовать с командой безопасности.

## Интересующие уязвимости

- RCE
- SQL injections
- Бизнес-логика
- Повышение привилегий (горизонтальное/вертикальное)
- Контроль доступа (cross/single tenant)
- Раскрытие конфиденциальной информации
- Недостатки аутентификации/авторизации
- SSRF/XXE с раскрытием чувствительной информации
- XSS (кроме Self-XSS)
- Выход за пределы контейнеризации

## Не принимаются

- Отчёты автоматизированных инструментов
- RCE без выхода из контейнера или горизонтального/вертикального перемещения
- Раскрытие неконфиденциальной информации
- Раскрытие публичной информации о пользователе
- Версии продукта/протокола без демонстрации уязвимости
- Небезопасные настройки в образах Маркетплейса
- Действия, недоступные через UI, без рисков безопасности
- Учётные записи без паролей/ПДн
- Уязвимости партнёрских сервисов без влияния на безопасность
- Blind SSRF без сканирования/запросов во внутреннюю инфру
- Атаки через сторонние сайты/библиотеки без реального влияния
- CSP без реального влияния
- Logout CSRF, Self-XSS, Framing, ClickJacking
- Атаки с полным доступом к оборудованию пользователя
- Реверс-инжиниринг / отсутствие обфускации
- Теоретические атаки без PoC
